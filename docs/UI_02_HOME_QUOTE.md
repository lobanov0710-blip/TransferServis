# UI-02 — главный экран и результат расчёта

Рабочая ветка `ui/ui-02-home-quote-v1` основана на `ui/ui-01-brand-splash-v1`. Разрабатывать и проверять как **stacked PR**; слияние UI-02 возможно только после принятия UI-01.

## Изменения
- Главный экран: компактный заголовок, форма маршрута выше рекламных преимуществ; предупреждение о неподтверждённой заявке сохраняется перед формой.
- Кнопка **«Поменять адреса местами»** только меняет текст в двух полях. Не выполняет API-вызов, не создаёт заявку и не сбрасывает защитную блокировку.
- Сохраняются идентификаторы `fromInput`, `toInput`, `tariffToggleGroup`, `buttonComfort`, `buttonBusiness`, `buttonMinivan`, `calculateButton`.
- Класс автомобиля остаётся один из трёх: Комфорт, Бизнес, Минивэн. Добавлен краткий текст о выбранном классе.
- Три кнопки тарифов имеют состояния выбора через `res/color/ts_tariff_button_{bg,stroke,text}.xml`: тёмно-синяя подложка, золотая рамка выбранного варианта, контрастные подписи. Группа и её ID сохранены.
- Экран расчёта: цена выделена фирменным золотым контуром. Сервер продолжает быть единственным источником цены.

## Визуальные исправления по API 35

По реальному скриншоту обнаружены пересечение верхнего overline с часами Android и некорректный перенос «Конфиденциально». Отступы `WindowInsetsCompat.systemBars | displayCutout` получены из UI-01, а повторяющийся узкий ряд преимуществ удалён: сведения остались в блоке «Поездка без лишних сложностей» ниже формы. Повторно проверить новую версию на screenshot API 35 и с масштабом шрифтов.

## Ограничения
- Никаких новых тарифов, изменённых API/DTO, запросов в production или автоматической повторной отправки заявки.
- Java + XML без переписывания архитектуры.
- Бронирование, восстановление и хранилище данных не меняются.

## Проверки
1. Android CI: `testDebugUnitTest`, `lintDebug`, `assembleDebug`, `assembleDebugAndroidTest` и аналогичный unsigned Release Gate.
2. Изолированный AVD: `HomeRouteSwapUiTest` — обмен адресов и текст подсказки тарифа. Тесты **не отправляют запросы**.
3. Ручная визуальная приёмка: 360dp / 411dp, масштабирование шрифта 1.0 и 1.3; длинные адреса, небольшие экраны.
4. В UI-03 не изменять сценарий защитной блокировки до отдельной ревизии.
